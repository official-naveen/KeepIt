# KeepIt — Chrome Extension Landing Page & Legal Hub

Official website repository and legal hub for **KeepIt**, a modern Chrome extension designed to save open tabs as named sessions, preserve native Chrome Tab Groups, auto-freeze idle background tabs to save memory, and sync across devices.

---

## 📌 Product Overview

* **Product Name:** KeepIt (KeepIt Legal & Web Hub)
* **One-Line Description:** The lightning-fast Chrome extension to save, organize, auto-freeze, and sync open browser tabs with native Tab Groups support.
* **Target Audience:** Developers, researchers, power users, and anyone overwhelmed by browser tab clutter.

---

## ⚡ The Problem KeepIt Solves

1. **High Memory (RAM) Consumption:** 50+ active tabs consume gigabytes of system memory, causing browser lag and fan noise.
2. **Lost Context & Crashes:** Unexpected browser crashes or computer restarts often wipe active research sessions.
3. **Tab Group Loss:** Restoring windows manually loses custom tab group labels, color badges, and structure.

---

## 🚀 Main Features

* **Instant Session Saver:** Save active windows & tabs in one click or using keyboard shortcut `Alt+Shift+S` (`Cmd+Shift+S` on Mac).
* **Native Chrome Tab Groups Preservation:** Automatically captures and restores tab group names, colors, and collapsed states into Chrome.
* **Auto-Freeze Memory Saver:** Automatically discards background tabs after a user-selected idle timer (15m, 30m, 60m), freeing up to 80% RAM without closing tabs.
* **Auto-Save Crash Recovery:** Background interval snapshots protect against unexpected Chrome crashes.
* **Folder & Live Search Organization:** Categorize saved sessions into custom folders and search through tab titles/URLs with instant checklist filtering.
* **Opt-In Cloud Sync & Peer Sharing:** Authenticate with Google Sign-in to sync sessions to Supabase Cloud or send session packages directly to another user's username.
* **OneTab & Bookmarks Import:** Effortlessly import existing OneTab text lists or Chrome bookmarks into organized KeepIt sessions.
